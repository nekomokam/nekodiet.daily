# Moka Shape Plan 🦋

11月4日〜12月8日のボディメイク・食事・体調記録用サイトです。

## 公開方法

この `README.md` と `index.html` をリポジトリの最上位にアップロードします。
GitHub の Settings → Pages → Build and deployment で `Deploy from a branch`、`main`、`/(root)` を選び保存します。

サイトURL: https://nekomokam.github.io/nekodiet.daily/

記録は利用端末のブラウザに保存されます。公開リポジトリには個人の記録をアップロードしないでください。
